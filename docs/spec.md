# 产品规格

## 地图

世界尺寸 1800 × 1200。视图缩放范围为 0.5–1.8，拖动时至少保留一部分世界内容在视口中。查看模式下对象不可移动；编辑模式下可拖动选中的普通岛屿和船。

## 岛屿

普通岛屿包含名称、主线/支线、当前事件、探索中/暂停/完成、small/medium/large 和世界坐标。归档后不显示在地图，可从归档抽屉恢复或永久删除。

## 神秘岛

系统岛不可删除或归档。无待完成事件时可捞漂流瓶；每轮最多看到三个不重复候选。接取后必须完成或放弃才能再次抽取。完成会写入带完成时间的历史。

## 持久化

所有状态写入版本化 localStorage。无效数据安全回退至空白初始地图。
